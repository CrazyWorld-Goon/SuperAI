# Источники радара

Отмечай `active: yes` только то, куда агент/ты реально заходишь в этом цикле.
Без активных источников радар не запускается.

## Шаблон строки

```
- name:
  type: telegram | discord | reddit | forum | reviews | avito | other
  url_or_how: 
  active: no
  notes:
```
