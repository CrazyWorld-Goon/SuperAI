# Контур A — Пикабу-автор

Цель: агент изучает спрос на Пикабу, пишет посты; человек на старте утверждает публикацию и ответы. Деньги — донаты площадки (не сторонние сборы).

## Метрики (иерархия)

Запрещены как цели агента: сумма плюсов за период, «как можно больше постов», сырое число подписчиков.

| Приоритет | Метрика | Смысл |
|-----------|---------|--------|
| 1 | плюсы/пост vs медиана ниши (тег/сообщество) | качество без клепания |
| 2 | Δ подписчиков на пост (или за неделю при стабильном темпе) | повторный интерес, не разовый плюс |
| gate | рейтинг ≥ 1000, подписчики ≥ 10, телефон | вход в монетизацию Пикабу |
| 3 | донаты/пост (после gate) | север канала $ |

Плюсы без сравнения с нишей не использовать для вывода «пост хороший/плохой».

## Этапы

1. **Спрос** — что плюсуют в выбранных нишах: темы, форматы, длина, теги; зафиксировать гипотезы (не абстрактные «идеи»).
2. **Черновик (L1)** — агент пишет файл в [`pikabu/drafts/`](pikabu/drafts/) по шаблону; `ai_tag: true` → на сайте тег «Контент нейросетей».
3. **Публикация (L1)** — человек читает черновик → при ок ставит `status: approved` → копирует на pikabu.ru → Publish → вписывает `published_url` / `published_at`. Автопубликации и L2/L3 нет, пока человек явно не снимет L1.
4. **Замер** — плюсы/пост vs медиана ниши; Δ подписчиков; комментарии как фидбек (разбор с человеком или по чеклисту).
5. **Итерация** — усилить то, что выше медианы; отбросить гипотезы-лузеры; не наращивать частоту ради объёма.
6. **Порог** — копить рейтинг/подписчиков до gate; без накруток и мультиаккаунтов.
7. **Донаты** — после gate: донаты/пост как главная метрика; плюсы/сабы остаются диагностикой.
8. **Ledger** — записать донаты/вывод; сверить с расходом на агента.

## Правила движения

- Режим публикации: **L1** (файл в репо → ручной Publish). L2/L3 не включать до явного решения.
- Нет замера по KPI₁/₂ → нет решения «ниша живая» или «масштабируем темп».
- Темп постов ограничивает человек, пока не снят режим «помощь агенту».
- Ответы в комментариях на старте — черновик агента → отправка человеком или с его ок.
- Эскалация к человеку: спор с модерацией, отключение монетизации, конфликт в комментариях, сомнение в честности маркировки ИИ.
