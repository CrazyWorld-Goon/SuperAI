# Режим Пикабу-стратега

Дата: 2026-07-26  
Роль: стратег роста (логика Instagram-системы → механики Пикабу).  
Ниша (временно, «на пару дней»): **бюрократия**  
Аудитория: **пользователи Пикабу** (лента Hot/Best + теги Паспорт / Бюрократия / волны)  
Цели клиента: **100 подписчиков** и **10 000 плюсов** (сумма)

Связанные артефакты: [`START-CHECKLIST.md`](START-CHECKLIST.md), [`demand/20260726-hot.md`](demand/20260726-hot.md), [`drafts/20260726-kod-podrazdeleniya-volna.md`](drafts/20260726-kod-podrazdeleniya-volna.md), KPI-контур [`../pikabu.md`](../pikabu.md).

## 0. Вердикт до системы

**Цели «100 сабов + 10k плюсов за пару дней в текстовой бюрократии» — Instagram-рамка, на Пикабу она почти наверняка разобьётся о медиану ниши.**

Доказательства среза 2026-07-26 (SSR HTML):

| Лента | Медиана рейтинга (rated>0) | Что доминирует |
|-------|----------------------------:|----------------|
| Тег **Бюрократия** /hot | **~24** | длинные [моё], жалобы, редкие волны |
| Тег **Паспорт** /hot | **~596** (раздута волной) | скрины + ответы на пост, 1 AI-хук ~3800 |
| **Best** | **~5881** | скрин/мем/конфликт/[моё], почти не «статья» |
| Общее **Hot** | тысячи на топе | видео, мем, волна, личная драма |

Арифметика (грубо):

- при медиане бюрократии ~24 → **~400 постов** до 10k плюсов;
- при серии удачных волн ~2000 → **~5 вирусных попаданий**;
- при Best-тире ~5000 → **2 поста**, но это не формат «текстовый ИИ без скрина/моё».

Подписчики на Пикабу **не равны** Instagram follow: плюс ставят чаще, чем подписываются. [Guessing] при 10k плюсах реалистичный коридор сабов без сильной серии/лица автора — порядка десятков, не «автоматом 100».

**Вывод стратега:** держим цели клиента как *north star*, но операционно бьём их на этапы. Иначе команда будет клепать объём и убьёт аккаунт минусами/скрытиями.

### Перевод целей в рабочие KPI (на ближайшие 48–72ч)

| Этап | Плюсы (накопительно) | Сабы | Смысл |
|------|---------------------:|-----:|-------|
| T0 → T1 (первые 3 поста) | 300–800 | 3–10 | доказать, что формат живой |
| T1 → T2 (волна / сильный хук) | 2 000–5 000 | 15–40 | первый «пробой» Hot |
| T2 → цель | 10 000 | 100 | только если есть повторяемая серия + оффер подписки |

Параллельно **не отменяем** KPI контура A: плюсы/пост vs медиана ниши + Δ сабов/пост ([`pikabu.md`](../pikabu.md)). Сумма плюсов — отчётная, не руль ежедневных решений.

## 1. Полный аудит роста

### 1.1. Текущее состояние аккаунта (факты)

| Параметр | Статус | Удар по росту |
|----------|--------|---------------|
| Опубликованные посты | **0** (есть только draft) | холодный старт, минимальная квота показов |
| Рейтинг автора | неизвестен / скорее ~0 | дольше модерация, меньше начальный push |
| Ниша | бюрократия на 2 дня | окно волны есть, но медиана тега низкая |
| Режим публикации | **L1** (ручной Publish) | лаг «готово → в эфире», пропуск тайминга Hot |
| Медиа-актив | нет своего скрина/арта | отрезаны топ-форматы Best |
| [моё] | нельзя фейкать | отрезан главный доверительный буст |
| AI-маркировка | `ai_tag: true` обязателен | честно, но часть аудитории минусует «нейросеть» |
| Профиль | не оптимизирован под серию | плюсы не конвертятся в сабы |
| Замер | нет | нельзя итерировать |

### 1.2. Аудит спроса в нише

**Что взлетает рядом с бюрократией сейчас**

1. **Волна** («Код подразделения») — скрин + 1 фраза / ответ на пост.
2. **Личная война с системой** — длинный [моё], эмоция + просьба опыта.
3. **HELP/отказ** — боль + призыв («отказывают в лечении»).
4. **Мета-юмор** про абсурд форм — коротко, без лекции.

**Что не взлетает в теге Бюрократия**

- длинные нейтральные эссе без лица автора;
- «полезная статья» без крючка конфликта;
- AI-текст без визуала и без участия в волне (в срезе тега AI = 0/8).

### 1.3. Воронка Пикабу (аналог IG funnel)

```
Показ (квота автора)
  → клик по заголовку
    → дочитывание / просмотр медиа
      → плюс / минус
        → коммент / сохранение
          → переход в профиль
            → подписка
              → донат (после gate: рейтинг≥1000, сабы≥10, телефон)
```

На Instagram узкое место часто «reach → profile visits».  
На Пикабу у нулевого аккаунта узкое место раньше: **квота показа → клик по заголовку → плюс в первые часы**.

### 1.4. Главные узкие места (ранжировано)

| # | Узкое место | Почему тормозит | Сила |
|---|-------------|-----------------|------|
| 1 | **Холодный старт + 0 публикаций** | нет сигнала алгоритму, нет базы сабов для первого часа | критично |
| 2 | **Формат ≠ рынок Hot/Best** | топ ест скрин/мем/видео/[моё]; наш черновик — текст | критично |
| 3 | **Плюс ≠ подписка** | цель 100 сабов требует серии и оффера в профиле, не одного вируса | критично |
| 4 | **Ниша «бюрократия» как тег слабая** | медиана ~24; сила только в стыке с волной/Паспорт/[моё] | высоко |
| 5 | **L1 + телефонный копипаст** | опоздание к волне = смерть охвата | высоко |
| 6 | **Нет визуального актива** | без скрина/своей картинки потолок ниже | высоко |
| 7 | **Нет системы комментов в первый час** | engagement кормит докрутку в Hot | средне-высоко |
| 8 | **Цель 10k плюсов как руль** | провоцирует спам/волны без серии → сабы не растут | средне |
| 9 | **AI-тег без компенсации** | минуса/недоверие, если хук слабый | средне |
| 10 | **Нет замера 24ч** | нельзя понять win/lose | средне |

**Главный диагноз:** рост тормозит не «плохой текст», а связка **холодный аккаунт × формат без медиа × цель в подписчиках без позиционирования серии**.

## 2. Позиционирование

### 2.1. Одна фраза (bio-logic)

**«Разбираю бюрократию так, чтобы было смешно — и чтобы в следующий раз вы не зависли на поле в форме.»**

Не: «полезный блог про госуслуги».  
Не: «мемы про паспорт» без лица.  
Да: **переводчик абсурда** — коротко, злободневно, с повторяемым форматом.

### 2.2. Обещание аудитории

После 3–5 постов человек должен сказать:

> «Это тот, кто про код подразделения / МФЦ / анкеты — подпишусь, чтобы не пропускать.»

### 2.3. Антипозиционирование (не делаем)

- политика ради охватов;
- чужие скрины без права;
- фейковое `[моё]`;
- экспертная юрконсультация (риск и минуса);
- «статья на 5000 знаков» в первые дни.

### 2.4. Серийный бренд (обязателен для сабов)

Рабочее название серии (выбрать одно и не прыгать):

1. **«Поле в форме»** — короткий разбор абсурдных полей/требований  
2. **«Код дня»** — ежедневный хук про документ/очередь/отказ  
3. **«Финальный босс бюрократии»** — уже зашло в волне; можно закрепить как рубрику

Рекомендация стратега: **«Поле в форме»** — шире, чем одна волна паспорта, переживает конец мема.

## 3. Система контента

### 3.1. Микс на 48–72 часа (бюрократия)

| Тип | Доля | Цель | Пример |
|-----|-----:|------|--------|
| A. Волна / ответ на пост | 40% | плюсы, Hot | код подразделения, МФЦ-скрины-волны |
| B. Короткий текст-хук серии | 40% | сабы, узнаваемость | «Поле в форме #1» |
| C. Вовлекающий вопрос | 20% | комменты → докрутка | «Какое поле в анкете бесило сильнее всего?» |

### 3.2. Форматы (вместо Reels / каруселей)

| IG-аналог | Пикабу-эквивалент | Приоритет сейчас |
|-----------|-------------------|------------------|
| Reels-хук 1с | **Заголовок ≤ 6–8 слов**, первая строка бьёт | P0 |
| Карусель | 3–7 коротких абзацев / нумерованный список | P0 |
| Мем | своя картинка с текстом **или** честный скрин своего документа (размытый) | P0 если появится медиа |
| Story | не нужен; вместо этого — **ответ на пост** в волне | P1 |
| Длинный гайд | длиннопост только после 1–2 коротких win | P2 |

### 3.3. Правила заголовка (hook system)

Формулы:

1. `Абсурд + объект` → «Код подразделения снова важнее даты рождения»
2. `Боль + HELP` → только на реальных историях
3. `Серия + номер` → «Поле в форме #1: код из смс, которого нет»
4. `Ответ на пост «…»` → когда волна жива

Запрет: нейтральные заголовки («О бюрократии», «Размышления о паспорте»).

### 3.4. Тело поста

- 500–1200 знаков на старте (не простыня);
- 1 мысль, 1 панчлайн, 1 вопрос в конце (CTA на коммент);
- маркировка AI;
- теги: `Бюрократия`, `Паспорт` (если в теме), `Юмор`/`Текст`, `Волна постов` (только если реально ответ), `Контент нейросетей`.

### 3.5. Контент-календарь на 6 слотов (не «каждые 2 часа»)

| Слот | Тип | Статус |
|------|-----|--------|
| 1 | Волна: код подразделения (уже есть draft) | draft готов |
| 2 | Серия «Поле в форме #1» | нужен черновик |
| 3 | Вопрос-вовлечение | нужен черновик |
| 4 | Ответ на свежую волну / свой скрин (если будет) | по событию |
| 5 | «Поле в форме #2» | после замера #1–2 |
| 6 | Лучший репак формата-победителя | после 24ч замеров |

Темп: **1 пост / 12–24ч**, не чаще. Частота ради 10k = минуса и выгорание ниши.

### 3.6. Окна публикации (рабочая гипотеза)

Пик активности аудитории (вторичные гайды + здравый смысл ленты): **08:00–10:00** и **18:00–21:00** (МСК).  
Правило: если волна горит — постить **в момент волны**, не ждать «идеального окна».

## 4. Вовлечённость (engagement system)

Первый час = Instagram «push Stories + reply DMs», только жёстче.

### 4.1. Протокол первых 60 минут после Publish

1. Самим **не накручивать** и не просить плюсы в лоб (минуса + токсичность).
2. Ответить на **каждый** адекватный коммент ≤15 мин.
3. Задать 1 уточняющий вопрос комментатору (удлиняет ветку).
4. Если тишина 20–30 мин — добавить **свой** осмысленный коммент-уточнение к посту (не «первый!»).
5. Человек утверждает спорные ответы (правило L1).

### 4.2. CTA, которые работают на Пикабу

- «Какой код/поле у вас самый проклятый?»
- «Было хуже, чем код подразделения?»
- «Кидайте названия полей — разберём в следующем „Поле в форме“»

CTA на подписку — **мягко и редко** (раз в 2–3 поста), иначе минуса:

- в конце: «Если серия зайдёт — она будет под этим заголовком, удобнее по подписке.»

### 4.3. Комменты как второй канал контента

Сильные ответы в чужих волнах (без спама ссылками на себя) = доверие + рейтинг с комментов.  
Лимит: **5–10 ценных комментов/день** в соседних постах ниши, не под каждым постом ленты.

## 6. Стратегия роста (growth engine)

### 6.1. Два двигателя

| Двигатель | Как работает | Метрика |
|-----------|--------------|---------|
| **Viral / Hot** | волны, хуки, скрины | плюсы/пост, попадание в Hot |
| **Series / Subs** | повторяемое имя рубрики + оффер | Δ сабов/пост |

Без второго двигателя 10k плюсов **не гарантируют** 100 сабов.

### 6.2. Рычаги роста по приоритету

1. **Опубликовать слот 1 сегодня** (волна ещё жива).  
2. **Визуал:** ваш размытый фрагмент паспорта/формы/ошибки Госуслуг — легально и сильно.  
3. **Серия с номером** со слота 2 — якорь подписки.  
4. **Коммент-протокол** каждый пост.  
5. **Сообщество** по теме (если есть живое) — доп. квота, не вместо Hot.  
6. Внешний трафик — только после 2–3 нормальных постов; сырой репост в Telegram на нулевом профиле мало даёт.

### 6.3. Чего не делать (антирост)

- мультиаккаунты / накрутка;
- копипаст чужих скринов волны;
- 5 постов в день «чтобы набрать 10k»;
- политика и хейт ради плюсов;
- смена ниши каждый день без замера (кроме заранее объявленного окна «пара дней»).

### 6.4. План достижения целей (реалистичная траектория)

**Фаза A — Пробой (дни 1–2)**  
Цель: 1 пост ≥ медианы Паспорт/волны **или** ≥ 5× медианы Бюрократия; ≥3 саба.  
Действия: Publish draft волны + профиль + коммент-протокол.

**Фаза B — Серия (дни 2–5)**  
Цель: 3 поста серии; средний плюс ≥ медианы ниши; ≥20–40 сабов.  
Действия: «Поле в форме» #1–#3 + 1 вопросник.

**Фаза C — Масштаб к 10k / 100**  
Цель: повторить победный формат; добрать плюсы вирусами, сабы — серией.  
Триггер продолжения: минимум **2 measured win** подряд. Иначе нишу «бюрократия» не растягивать — сменить угол (бытовые сервисы / Госуслуги UX), не бросая метод.

### 6.5. Критерий kill/scale

| Результат 24ч | Решение |
|---------------|---------|
| плюсы ≥ 2× медианы ниши и есть Δ сабов | scale формат |
| плюсы ~ медиана, сабы 0 | усилить хук + CTA серии + визуал |
| плюсы ≪ медианы / много минусов | kill угол, не «ещё 10 таких же» |
