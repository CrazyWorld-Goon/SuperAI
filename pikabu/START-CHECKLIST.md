Дата: 2026-07-26  
Режим публикации: **L1** (черновик в репо → человек копирует на сайт → Publish).

## Короткий ответ про аккаунт

| Кто | Аккаунт Пикабу | Логин/пароль агенту |
|-----|----------------|---------------------|
| Человек | **нужен** — без него Publish невозможен | себе; в репо и чат агенту **не класть** |
| Агент (L1) | не нужен | не нужен — агент пишет файл, не логинится |
| Агент (L2/L3, позже) | тот же аккаунт человека | только если явно снимете L1 и решите, как хранить сессию |

Итого: аккаунт нужен **вам**, не мне. На L1 я готовлю текст; кнопку Publish жмёте вы.

## Перед каждым Publish (L1)

- [ ] Черновик `status: draft` → вы прочитали → `status: approved`
- [ ] Заголовок, текст, теги скопированы на сайт
- [ ] Если `ai_tag: true` — на сайте стоит тег **«Контент нейросетей»**
- [ ] Нет чужих фото/скриншотов без права; нет фейкового тега **[моё]**
- [ ] После Publish: вписать `published_url`, `published_at`, `status: published`

## Через ~24 часа после Publish

- [ ] `pluses_24h`
- [ ] `pluses_niche_median_24h` (медиана по выбранной нише/тегу, не по всему Горячему)
- [ ] `delta_subs`
- [ ] `result`: `win` / `lose` / `unclear` → `status: measured`

## Для монетизации (не старт, но цель контура)

- [ ] Рейтинг профиля ≥ 1000
- [ ] Подписчики ≥ 10
- [ ] Телефон привязан (порог Пикабу)
- [ ] Донаты только через площадку; сторонние сборы — нет
- [ ] Ledger: донаты vs расход на агента

## Чего агенту от вас не нужно на L1

- пароль / cookies / 2FA
- доступ к почте аккаунта
- карта / реквизиты вывода

## Открытая развилка (решает человек)

**Ниша на 5 постов.** Рекомендация: не цепляться только за однодневные волны («код подразделения»), а выбрать устойчивый тег, где можно писать текст без чужих картинок — например бытовая бюрократия / жизнь с документами **или** короткие разборы «почему волна взлетела» в юморе.  
Почему: KPI₁ = плюсы/пост vs медиана **ниши**; Горячее целиком — плохой бенчмарк для нового профиля.
