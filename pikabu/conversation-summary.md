# Выжимка: Пикабу как канал заработка

Дата сессии: 2026-07-25 … 2026-07-27  
Контекст: репозиторий SuperAI, переход от «радар болей → услуга» к контуру автора на pikabu.ru.

## Исходный запрос

Оценить, насколько pikabu.ru защищён от парсинга и можно ли читать статьи агентом. Дальше — идея агента-автора, метрики, способ публикации.

## Технический вывод по площадке

- Периметр: **DDoS-Guard** (не Cloudflare); на низкой частоте обычный HTTP отдаёт **200** и HTML постов.
- Текст поста: **SSR**, агент (WebFetch) читает ленту и тело story без браузера.
- Комментарии: в HTML почти нет, подгрузка через ajax; `/api/*` и `/ajax/*` в robots Disallow.
- Официального публичного API нет; кодировка страниц `windows-1251`.
- Имитация «живого» пользователя (stealth-браузер, мышь) для **чтения постов не нужна**; для массового обхода — отдельный ToS/антибот-риск, на старте не берём.

## Уточнение идеи продукта

Не «парсить чужих ради лидов», а:

- **Пикабу = канал заработка** (посты → аудитория → донаты).
- ИИ пишет полезные посты; на старте **человек помогает** (качество, Publish, ответы).
- Срез мнений площадки — быстрая проверка гипотез; донаты — целевые деньги контура.

Поправка по правилам: один профиль + работа автора ≠ автоматически «вред ресурсу» (п. 4.3). Релевантны спам/флуд, тег **«Контент нейросетей»**, порог монетизации (рейтинг ≥ 1000, ≥ 10 подписчиков, телефон), запрет мультиаккаунтов и сторонних донат-систем.

## Метрики (зафиксировано)

Запрещены как цели: сумма плюсов, максимальная частота постов, сырое число подписчиков.

1. **плюсы/пост vs медиана ниши** (тег/сообщество)
2. **Δ подписчиков на пост** (или за неделю при стабильном темпе)
3. после gate — **донаты/пост**

Плюсы без сравнения с нишей не считать вердиктом «хороший пост».

## Организация работы

Не «демон раз в N часов клепает посты» на старте.

Цикл: спрос → черновик → человек Publish → замер ~24ч → итерация.  
Черновики по событию «нужен пост», не по голому таймеру (таймер стимулирует объём).

Cron/автозапуск — после 5–10 измеренных постов, когда правила стабильны. Сейчас — агент в Cursor по запросу + файлы в репо.

Ниша на окно ~2 дней: **бюрократия** (серия «Поле в форме»). Режим стратега: [`STRATEGIST-MODE.md`](STRATEGIST-MODE.md).

## Публикация: L1

| Уровень | Суть | Статус |
|--------|------|--------|
| L1 | файл в `pikabu/drafts/` → копипаст → Publish вручную | **старт** |
| L2 | агент заполняет форму, Publish жмёт человек | позже |
| L3 | автоPublish | не берём на старте |

Артефакты: `pikabu/drafts/_TEMPLATE.md`, статусы `draft → approved → published → measured`.

## Пайплайн в репо

- `pipeline.md` — два контура: **A Пикабу (активный)**, **B радар болей (пауза)**; общий ledger.
- `pikabu.md` — этапы и KPI контура A.
- `radar/*` — контур B, на паузе.
