Ограничения площадки ([help](https://help.pikabu.ru/article/39834)): ник **4–16** символов; только **латиница, цифры, одна точка** (не с краю). Свободность: `pikabu.ru/@НИК` → **404** ≈ свободен (проверить ещё раз в момент регистрации).

## Рекомендуемый пакет (брать целиком)

| Поле | Значение |
|------|----------|
| **Ник** | `pole.forme` |
| **О себе** | `«Поле в форме»: короткий разбор бюрократического абсурда. Без юрсоветов — с узнаванием.` |
| **Серия в постах** | Поле в форме #N |
| **Тон** | ирония, коротко, без экспертной позы |

Почему этот ник: читается как серия, не привязан к мему «код подразделения», длина 10, точка допустима, на 2026-07-26 URL дал 404.

Запасной ник (если `pole.forme` займут в момент регистрации): **`form.pole`** → затем **`poleforme`**.
